## 01 初回紹介

## ストーリーの流れ

「採用のお金を働く本人の力に」という思想を宣言し、続けて「できることは4つだけ（探す・話す・採用・ボーナス）」の全体像を渡す。その後は4ステップを時系列で深掘りし、①探す（ひとこと・写真・距離）→②話す（2つの入口・面談日調整）→③採用（採用費を本人への入店ボーナスに）とつなぐ。仕組みを伝えたあと、AI店舗検索・接客タイプ診断・オコジョガイドを「キャストが集まり、はじめてでも使える理由」としてまとめ、料金（リリース前登録0円）で費用の不安を解消し、店舗登録の呼びかけで締める。

最初の15秒をコンセプトと全体像、次の32秒を4ステップの時系列、10秒を選ばれる理由、9秒を料金、最後の6秒を登録の呼びかけに使う。操作手順の説明は別の動画で扱う。

## ナレーション通し読み

紹介料で回ってきた夜職の採用を、働く本人の力に。採用の常識を変える、ミセチョク。

ミセチョクでできることは、シンプルに4つ。探して、話して、採用して、入店ボーナスを本人へ。この流れを、順にご紹介します。

まずは探す。新しいひとことから今の希望を、写真のスワイプから雰囲気を。近さや働き方でも、お店に合うキャストを絞り込めます。

気になったら、お店から直接声をかけられます。キャストからの問い合わせも、同じトークに届きます。条件をすり合わせ、面談日の調整まで画面で完結します。

採用が決まったら。これまで紹介料に消えていた採用費を、条件を満たした本人への入店ボーナスに。申請から受け取りまで、進み具合を画面で確認できます。

キャスト側には、AI店舗検索や接客タイプ診断。お店を知ってもらう入口が増え、診断は相性を考える材料になります。オコジョのガイドで、はじめてでも迷いません。

料金はシンプルです。いまはリリース前登録キャンペーンで、初回登録もBasicの月額も0円。Premiumでは、スカウト枠の拡大などもご用意しています。

まずは、店舗登録から。営業担当がその場でサポートします。

## 場面ごとの演出・撮影指定

### 1. 紹介料で回る採用を、本人に届く採用へ

**伝えること：**

- 高額な紹介料が当たり前だった業界の慣習を変え、採用にかけるお金を働く本人への後押しに使うという思想。
- スカウト会社そのものではなく、店舗の負担になってきた慣習を変える。攻撃ではなく対比で伝える。
- 3点訴求（もっとお店を知ってもらえる／求人コストを大幅カット／成約しなければ無料）を宣言とセットで見せる。

**映像・演出：** 見出し→3点バッジ→アプリ画面の順に表示。0–2秒でロゴと宣言、2–4秒でバッジ3点、4–6秒は全体を止めて見せる。仕組みの箇条書きは置かず、表紙は宣言とビジュアルに絞る。

**実画面への差し替え：** 正式なロゴと白背景の表紙。DISCOVERYの実演画面2枚（店舗側・キャスト側）を添える。現在のスライドでは、現行テンプレートを架空データで表示した静止画を使用。人物と店舗の写真は生成した架空素材。

### 2. できることは、4つだけ

**伝えること：**

- 探す→話す→採用→ボーナスの4ステップが全体像。ここで地図を渡し、以降を深掘りとして聞ける状態にする。
- 4つがひとつの画面（サービス内）で完結すること。

**映像・演出：** 見出し→4ステップを左から順に点灯→下のまとめ文の順に表示。1ステップずつ短い間を置く。

**実画面への差し替え：** 説明図のみ（役割・確認項目を整理した図）。実画面は次の場面から。

### 3. ①探す｜新しいひとことと写真から

**伝えること：**

- SEARCHのひとこと更新順で、最近発信したキャストの様子を見て声をかけられる。
- 写真中心のDISCOVERYを上下スワイプし、雰囲気から出会える。
- 位置情報や働き方・経験でも絞り込める。
- 最近の発信は活動の手がかり。勤務可能・返信の早さは本人に確かめる。

**映像・演出：** 見出し→SEARCHのひとこと更新順→DISCOVERYのスワイプ→位置・条件の順に見せる。投稿を読む・写真をめくる自然な動きで使い心地を伝える。

**実画面への差し替え：** /shop/search?tab=list のひとこと更新順・位置設定・詳細条件、/shop/home の上下スワイプ。オンライン中や返信の保証とは説明しない。現在のスライドでは架空データの静止画を使用。

### 4. ②話す｜直接トークして、面談へ

**伝えること：**

- 店舗発（直接スカウト）とキャスト発（問い合わせ）の2つの入口が、同じトークにつながる。
- トークで条件をすり合わせ、面談日の候補提示・選択・確定まで画面で完結する。

**映像・演出：** 見出し→店舗発・キャスト発の会話例→下のまとめ文の順に表示。左右に並べた同じ会話例で、入口が2方向であることを見せる。

**実画面への差し替え：** 店舗プロフィール閲覧・トーク送信、キャスト側の受信・返信、面談候補日の操作。店舗・キャスト・メッセージは架空の説明例。

### 5. ③採用｜採用費を、本人への入店ボーナスに

**伝えること：**

- これまで間に入る会社へ支払っていた採用費を、条件を満たしたキャスト本人への入店ボーナスに変えられる。
- 申請・店舗承認・入金・運営振込・本人受領まで、進み具合を確認できる。
- 本人への報酬と運営手数料を分けて示し、費用の使い道が変わることを伝える。

**映像・演出：** 見出し→「これまでの慣習→ミセチョク」の対比図→申請から受領までの流れの順に表示。手数料の注記を常時表示する。

**実画面への差し替え：** /shop/mypage/management、ボーナス条件は /shop/recruits/preview。実際の送金操作は映さない。仕組みの説明図。入店ボーナスには達成条件があります。運営手数料は別途。

### 6. キャストが集まり、はじめてでも使える

**伝えること：**

- AI店舗検索・接客タイプ診断がキャストの入口になり、自店を知ってもらう機会が増える。
- 診断は本人が言葉にしにくい接客傾向の整理。相性を考える材料であり、保証ではない。
- オコジョの画面別ガイドが使い始めを支える。ガイドは画面の案内で、個別の質問に回答する機能ではない。

**映像・演出：** 見出し→AI検索と診断の画面→オコジョガイドの順に表示。「キャストが集まる理由」と「はじめてでも使える安心」をひとつの場面でまとめる。

**実画面への差し替え：** /cast/search/ai の候補求人、接客タイプ詳細、ガイドが有効な店舗画面。オコジョ画像は public/assets/images/guide/guide-character.png をそのまま使用。

### 7. 料金｜リリース前登録で、0円ではじめる

**伝えること：**

- 通常料金は、初回登録（マイページ・求人作成まで支援）5万円＋Basic月額5,000円。
- 2026年度中のリリース前登録は、初回登録とBasic月額が0円。
- Premium（月29,000円）はスカウト送信 1日5件→30件・閲覧キャスト一覧・AI検索の優先表示。
- 入店ボーナス・運営手数料は別途。正式料金は公開前に最新内容を確認する。

**映像・演出：** 見出し→キャンペーンの0円→通常価格の取り消し表示→Premiumの順に見せる。料金パネルを1枚の主役として大きく表示する。

**実画面への差し替え：** 料金の説明図。金額・提供条件は公開前に最新の料金資料と照合する。

### 8. まずは、店舗登録から

**伝えること：**

- 店舗登録→掲載準備→採用活動への3ステップ。
- 営業担当がその場で登録から掲載準備までサポートする。
- 登録と求人公開の準備は別の段階。詳しい使い方は02・03の動画で説明する。

**映像・演出：** 見出し→登録3ステップ→サポート案内の順に表示。最後の2秒は締めの文を残す。

**実画面への差し替え：** ロゴと文字中心。正式な店舗登録先が確定した場合のみQRコードを追加する。デモ環境のURLは使わない。

## 制作時の前提

- HTMLは構成・台本の検討用。自動プレビューは音声なし（初回紹介は72秒）。音声収録・動画生成は含めない。
- 初稿は落ち着いた営業トーン。短い字幕とアプリ画面で伝える。想定尺に収めるため、収録前に実際の読み合わせで速度と間を調整する。
- SEARCH・DISCOVERY・AI店舗検索・接客タイプ・オコジョガイドは、現行のBladeテンプレートとCSSに架空データを渡して表示した静止画。実環境の会員データではない。人物と店舗の写真は生成した架空素材。登録・会話・支払いの図は手順の説明図であり、実際の画面の再現ではない。動画では撮影メモに沿って実演画面を収録する。
- 検索結果からプロフィール、トーク、日程調整へとつながる操作の流れと、写真・条件が見やすい表示を見せる。他社比較や業界唯一といった未検証の主張は入れない。
- AI検索と診断はキャストの利用拡大を目指す仕掛けであり、店舗の発見機会と候補者理解にも役立つ機能として扱う。診断は回答に基づく接客傾向の整理であり、店との相性を自動で保証・判定するものとして説明しない。登録者数の増加実績、返信率、採用率などを裏付けなく表示しない。
- 料金は、初回登録（登録支援つき・通常5万円）／Basic月額（通常5,000円）／Premium月額（29,000円）。2026年度中のリリース前登録は、初回登録とBasic月額が0円。入店ボーナス・運営手数料は別途で、ボーナスには達成条件がある。提供条件と正式料金は公開前に最新内容を確認する。
- 正式な登録URLが指定されていないためQRコードは入れていない。訪問営業で担当者が登録を支援する締め方とする。

オコジョの画像はアプリにある public/assets/images/guide/guide-character.png をそのまま使用。ガイドの案内は画面ごとの設定に基づく。動画では表示が有効な画面と案内文を確認して撮影する。

## 02 登録・日々の運用

想定尺：4:00／12場面

写真選び、登録・求人公開から、日々の確認と更新まで。

### 01. 登録と日々の運用

登録・掲載準備／0:00–0:10（10秒）

**ナレーション：** お店の魅力が伝わる登録から、毎日の採用活動まで。ミセチョクを使い始める流れをご紹介します。

**伝えること：**

- アカウント作成から求人公開までを一連で見せる。
- 後半は、使い続けるための確認・更新の習慣を紹介する。

**映像・演出：** 見出し→図・画面の注目箇所→確認ポイントの順に表示。ロゴ、タイトルの順に表示。前半と後半のテーマを一つずつ示す。

**撮影する画面・補足：** 表紙は文字中心。次の場面から実演用店舗の登録画面へ。 現在のスライドでは、現行テンプレートを架空データで表示した静止画、または役割・確認項目を整理した説明図を使用。人物と店舗の写真は生成した架空素材。

### 02. 登録前に用意するもの

登録・掲載準備／0:10–0:28（18秒）

**ナレーション：** まずは店舗情報、管理用のメールアドレス、店内写真を準備します。求人公開に必要な書類も確認しましょう。メールは、その後も店舗で確認できるものを使います。

**伝えること：**

- 店舗が管理できる連絡先を使う。
- 写真と必要書類を事前に確認し、入力中の手戻りを減らす。
- メールの確認担当と必要な店舗情報を準備し、登録中の手戻りを減らす。

**映像・演出：** 見出し→図・画面の注目箇所→確認ポイントの順に表示。準備するものを上から順に表示。メールの説明では「店舗が管理」の文字を強調する。

**撮影する画面・補足：** 店舗登録フォームの入力項目と、書類提出の案内。実在の個人情報は映さない。 現在のスライドでは、現行テンプレートを架空データで表示した静止画、または役割・確認項目を整理した説明図を使用。人物と店舗の写真は生成した架空素材。

### 03. 写真で伝わるお店の雰囲気

登録・掲載準備／0:28–0:52（24秒）

**ナレーション：** メイン写真は、明るさや清潔感、席の雰囲気が伝わる一枚に。追加の写真では、店内全体、カウンター、入口などを見せます。切り抜いた後も見せたい場所が残るか、顔や個人情報が写っていないかを確認しましょう。

**伝えること：**

- 実際に働く場所が想像できる写真を使う。
- 同じ構図を並べず、異なる場所や特徴を見せる。
- 切り抜きと写り込みを確認する。
- 写真の構図と掲載後の見え方を、具体例で理解できるようにする。

**映像・演出：** 見出し→図・画面の注目箇所→確認ポイントの順に表示。写真を選ぶ場面、切り抜き、キャスト側の見え方の順に見せる。ひとつの写真に注目する時間を確保する。

**撮影する画面・補足：** 店舗登録の写真選択・トリミング、店舗ギャラリー。図中の素材は構成用イラスト。 現在のスライドでは、現行テンプレートを架空データで表示した静止画、または役割・確認項目を整理した説明図を使用。人物と店舗の写真は生成した架空素材。

### 04. アカウント作成と初回ログイン

登録・掲載準備／0:52–1:16（24秒）

**ナレーション：** 店舗情報と写真を入力し、プランと内容を確認します。パスワードの設定と規約への同意は、店舗の担当者自身で行います。届いた認証メールを確認し、自分の端末でログインできたら、求人の準備へ進みましょう。

**伝えること：**

- 本人が内容・パスワード・規約を確認して登録する。
- メール認証と自分の端末でのログインまでを見せる。
